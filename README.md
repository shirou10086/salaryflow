# 薪流 SalaryFlow

> 把「这个月还有多少工资没到手」变成通知栏里一个**一直在涨的数字**。
> 灵感来自 [Jack-Cherish/zhuanlema](https://github.com/Jack-Cherish/zhuanlema) 的实时工资计算，以及鲨鱼记账一类的流水记账体验。

薪流是一个**纯本地、不联网**的安卓应用：

- 通知栏常驻显示「今日已赚」+「已攒钱」+「今日支出」，金额每秒自动上涨；
- 到发薪日自动把虚拟工资按攒钱比例存进「攒钱罐」，并播放一次「虚拟工资 → 真钱落袋」的结算动画；
- 支出 / 收入 / 攒钱三合一的快速记账，带月度统计、分类占比、攒钱曲线；
- 附带一个桌面小组件，不解锁手机也能看到今天的工资进度。

数据只写在本机 SQLite / DataStore 里，没有账号、没有网络权限、没有埋点。

## 功能

### 1. 通知栏实时工资

![通知栏](docs/screenshots/notification.png)

- 前台服务每秒刷新一次通知（可在设置里调成 1 / 5 / 10 / 60 秒）；
- 通知内容：`今日已赚`、`已攒`、`今日支出`、`距下班倒计时`、`距发薪日`、`每秒 +¥0.0159`；
- 通知栏可直接「记一笔」「暂停 / 继续」「停止」；
- 支持隐藏金额（显示 `¥••••`），锁屏时不泄露工资数字；
- 重启手机后可按设置自动恢复（Android 12+ 以后台限制为准，失败会自动降级为下次打开 App 时恢复）。

### 2. 发薪日自动结算 + 落袋动画

![发薪日动画](docs/screenshots/payday.png)

- 结算周期：`上月发薪日次日 → 本月发薪日`（发薪日可设为 1–31，月末自动按当月天数收敛）；
- 到发薪日自动按「月薪 × 攒钱比例」写入攒钱罐，并可选同时记一条「工资」收入；
- 通过 `settlementKey` 做幂等去重，多入口触发（通知服务 / WorkManager / 打开 App）也只会入账一次；
- 连续多期未结算会自动补记（最多 24 期）；
- 结算后播放一次「金币落进罐子 + 金额滚动」的全屏动画；
- 也可以随时点「提前入账本期」，把本期已经虚拟累积的部分先存进罐子。

### 3. 记账

![账本](docs/screenshots/ledger.png)

- 三分类：支出 / 收入 / 存入攒钱罐 / 从罐中取出；
- 9 个内置支出分类、5 个收入分类，快速记一笔只需两步；
- 按月浏览、按天分组、支持删除；
- 发薪日自动记账与手动记账在同一条流水里展示，会自动打上「自动」标记。

### 4. 统计

![统计](docs/screenshots/stats.png)

- 本月支出 / 收入 / 存入攒钱罐；
- 近 6 个月支出柱状图；
- 本月支出分类环形图；
- 攒钱罐逐日余额曲线。

### 5. 桌面小组件

2×2 小组件显示今日已赚、已攒钱与状态，由前台服务顺带刷新；即使没开通知栏服务，也会在组件自身更新周期内刷新。

## 计算规则

| 指标 | 公式 |
| --- | --- |
| 日薪 | `月薪 ÷ 每月计薪天数`（默认 21.75 天） |
| 每秒工资 | `日薪 ÷ 每个工作日的计薪秒数` |
| 今日已赚 | `今天从上班到现在的计薪秒数 × 每秒工资` |
| 计薪秒数 | `(下班时间 - 上班时间) - 不计薪的午休` |
| 攒钱罐单次结算 | `月薪 × 攒钱比例`（发薪日固定金额，避免当月工作日多少影响金额） |

几个刻意的设计选择：

- **实时数字 vs 结算金额**：屏幕上的虚拟数字按 21.75 天/秒级累积，发薪日实际入账按固定月薪计算，两者不混用，账目更可预期；
- **午休是否计薪**可配置；
- **工作日**可配置（默认周一到周五），法定节假日调休需要自行调整「工作日」设置。

## 构建

环境要求：JDK 17、Android SDK（`compileSdk 35`、`build-tools 35.0.0`）。

```bash
# 1. 指向本机 SDK
echo "sdk.dir=$HOME/Android/Sdk" > local.properties

# 2. 跑测试、Lint 并编译 Debug 包
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug

# 产物
app/build/outputs/apk/debug/app-debug.apk
```

单独运行单元测试（金额精度 / 薪资时钟 / 发薪日周期 / 结算补记规则）：

```bash
./gradlew :app:testDebugUnitTest
```

安装到已连接设备或模拟器：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Release 构建需要自己的签名配置（仓库不含任何密钥）。

## 技术栈

- Kotlin 2.0 + Jetpack Compose（Material 3）
- Room（流水账本）+ DataStore（设置）
- 前台服务 `specialUse` + NotificationCompat（实时通知）
- WorkManager（每日结算兜底 + 下一个发薪日定时结算）
- AppWidgetProvider（桌面小组件）
- 单元测试覆盖纯 Kotlin 的 `SalaryClock` 计薪引擎

```
app/src/main/java/com/salaryflow/app/
├── core/        SalaryClock 计薪引擎、金额与时间格式化（纯 Kotlin，可单测）
├── data/        Room 实体 / DAO / 仓库、DataStore 设置、发薪日结算
├── service/     前台通知服务、开机广播、结算通知
├── work/        WorkManager 结算调度
├── widget/      桌面小组件
└── ui/          Compose 界面（首页 / 账本 / 统计 / 设置 / 结算动画）
```

## 隐私

- 没有 `INTERNET` 权限，代码里不存在任何网络请求；
- 所有金额、设置、流水都保存在应用私有目录；
- Android 云备份可能包含本机数据库与设置数据（可在系统设置里关闭）；
- 唯一用到的敏感权限是通知（Android 13+）与前台服务，用于常驻通知栏。

## 使用建议

1. 首次打开先在「设置 → 薪资与工时」填写月薪、上下班时间、计薪天数；
2. 回到首页点右上角铃铛开启通知栏实时工资，并在系统弹窗里允许通知；
3. 发薪日设为实际到账日，攒钱比例按自己的习惯来（默认 20%）；
4. 日常花销用通知栏的「记一笔」或账本页的加号，两秒钟记完；
5. 想要仪式感可以点首页的「发薪仪式」试播一下落袋动画。
